# Caplo 录屏与剪辑

Caplo 是独立应用，本技能通过可用的 Computer Use 控制其界面；它不提供已经验证的程序控制接口。保持用户已有工程与设置，按本次要求操作。使用 Caplo 前确认用户的用途符合 Caplo 自身许可证；其源码许可为 PolyForm Noncommercial，商业用途需另获授权。

## 准备

- 确认 macOS 已安装 Caplo；检查实际版本和界面，不假设所有版本相同。
- 明确录制目标和输出要求；默认仅捕获指定窗口，麦克风、摄像头和系统音频仅在用户要求时启用。先检查当前状态，避免录入私人信息或用户不想录制的内容。
- 启动 Caplo，处理录制权限：需要系统授权时让用户操作；不要绕过权限。尊重已有设置，不重置系统或应用授权。
- 启动演示目标并准备到起始状态。仅用本环境允许的工具控制 GUI，操作后读取当前状态，不能依赖旧截图坐标。

## 录制与导出

1. 在 Caplo 界面选择窗口或用户指定的范围；识别目标名称并核对选中状态。查看音源及摄像头状态。
2. 启动录制，确认倒计时结束、录制确实开始。随后使用 Computer Use 或浏览器工具完成已授权的演示，等待画面稳定后再做下一步。
3. 停止录制并确认保存。优先读取录制控制条，找到“停止录制并保存”后点击；Caplo 0.3.0 的窗口录制已验证可以这样操作。浮动录制条有时无法读取：先确认已开始录制（默认倒计时 3 秒并检查录制状态或新工程），然后通过 Caplo 菜单的“退出 Caplo”正常退出，Caplo 会先停止并保存。不要强制结束进程；若出现保存错误或退出被拒，处理提示或请用户停止。正常退出会关闭 Caplo 的窗口：先确认不存在用户正在操作的未保存内容或正在导出的项目。重新启动 Caplo，在“项目中心”找到并打开本次新工程，核对时长与内容。此方法在 Caplo 0.3.0 的全屏无音频录屏中验证过，其他版本须验证；不能确认录制开始或停止时不要声称成功。保留原始工程；明确区分原始录制和导出文件。
4. 若用户要求，使用编辑器中实际可见的自动缩放、字幕或静音清理功能；对生成字幕逐句核查，语义剪辑须依据转录与声音，不把静音自动识别当作口误判断。先验证实际更改，再导出。
5. 在导出界面选所需格式与保存位置；文件已存在时使用新文件名。等待导出结束并用 ffprobe 或播放器核实文件可读、时长和音视频轨道。报告文件路径及实际完成内容；失败或无法验证时明确说明。

## 功能边界

Caplo 官方说明支持录屏、自动镜头、字幕、本地语音识别、静音处理和视频导出，具体取决于安装版本、系统权限与界面可操作性。不要把界面没有验证的步骤、自动化精剪或中文识别效果当成已经测试成功；不能操作时如实报告并提供用户可执行的步骤。仅针对本次请求操作，不改变或删除其他工程。

## 经验验证（Caplo 0.3.0）

实测可操作指定 Chrome 窗口录制和停止、导入 SRT、修改单条字幕、导出 SRT/GIF、增加并调整聚焦、去除口播静音。中文合成口播样片仅识别了最后一句，转写必须与原音核对完整性。静音清理不等同于语义精剪；网页操作的录制、英文翻译、章节和精准语义剪辑未完成端到端验证。
